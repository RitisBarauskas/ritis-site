# ritis.dev

Сайт Ритиса Бараускаса: форматы работы, бронь с оплатой и юридические страницы.

## Состояние

Демо. Окно брони отправляет платные форматы в API (`api/`) и уводит на оплату Flitt — пока на тестового мерчанта, деньги не списываются; после оплаты страница `/booking/` показывает её статус. API ещё не развёрнут, поэтому на выложенном сайте бронь не работает, только локально. Заявка на бесплатный разбор и лист ожидания Veritas — заглушки. Внешние ссылки (GitHub, LinkedIn, YouTube, Telegram) рабочие.

## Структура

- `web/` — страница на [Astro](https://astro.build), собирается в статические файлы.
  - `src/pages/` — страницы: главная, `/booking/`, оферта, условия возврата, конфиденциальность, реквизиты; `src/sections/` — секции главной, `src/components/` — шапка, подвал, окно брони, общие части юридических страниц.
  - `src/scripts/` — код в браузере; `booking-api.ts` — запросы к API брони, `booking-page.ts` — страница `/booking/`.
  - `src/site.config.ts` — ссылки, форматы и реквизиты продавца; цены берёт из `shared/catalog.json`.
  - `src/assets/img/` — фото; Astro сжимает их в AVIF/WebP под нужные размеры.
  - `tests/e2e/` — браузерные тесты на Playwright.
- `api/` — бронь и оплата на FastAPI, подробности в [api/README.md](api/README.md).
- `shared/catalog.json` — форматы и цены: по ним собирается сайт, а API берёт цену брони и текст заказа для Flitt.

## Локально: сайт

Нужны Node.js 22.23+ и установленный Google Chrome (для тестов).

```sh
cd web
npm ci
npm run dev        # http://127.0.0.1:4321, запросы /api уходят на 127.0.0.1:8000
npm run build      # сборка в web/dist
npm run check      # проверка типов и фото без метаданных
npm test           # пересобирает сайт и гоняет браузерные тесты; API в них подменён, настоящий недоступен
npm run mutations  # ломает ключевые правила брони по одному и проверяет, что их тесты падают
```

Чтобы пройти бронь целиком, рядом с `npm run dev` запустите API — см. [api/README.md](api/README.md).

## Фото

Репозиторий публичный. Перед тем как положить фото в `web/src/assets/img/`, удалите из него метаданные: EXIF (GPS, камера, даты), XMP, IPTC. `npm run check` падает, если они остались. Цветовой профиль (ICC) можно оставить.
